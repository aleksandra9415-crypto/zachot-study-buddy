# Зачёт: AI for Study

Создай лендинг образовательного AI-сервиса «Зачёт» на React + Tailwind. В этом промпте — фундамент проекта и верхняя половина главной страницы. Нижняя половина будет отдельным промптом, не добавляй её сейчас.

1. Константа бренда

Создай src/config/brand.ts:

export const BRAND = {
  name: "Зачёт",
  tagline: "AI для учёбы",
};


Название используй ТОЛЬКО через эту константу, нигде не хардкодь строку «Зачёт». Название рабочее и будет меняться.

Везде в текстах пиши «Зачёт» через букву ё.

2. Дизайн-токены

Задай в tailwind.config и в CSS-переменных ровно эти цвета:

navy-950   #062132
navy-900   #132A3F
navy-700   #1E3D57
orange-500 #FC6116
orange-100 #FFE7DA
teal-500   #56AFB1
teal-200   #BCDFE0
white      #FFFFFF
bg         #F1F4F6
muted      #6B7C8C


Градиент тёмных блоков: linear-gradient(135deg, #062132 0%, #132A3F 100%).

Правила использования, соблюдай строго:

Фон страницы — bg. Карточки — white.

Основной текст — navy-900. Вторичный текст — muted.

orange-500 только на: кнопки-действия, активные состояния, крупные цифры, иконки-акценты. НЕ используй оранжевый для обычного текста и ссылок — он не проходит по контрасту на белом.

teal-500 — второй акцент, для иконок и декоративных элементов.

3. Типографика

Шрифт Inter, начертания 400 / 500 / 700.

Заголовки — 700, плотный трекинг (-0.02em).

Заголовки НЕ в верхнем регистре: русский текст капсом читается хуже.

Размеры на десктопе: H1 56px, H2 40px, H3 20px, основной текст 16px, мелкий 14px.

4. Базовые размеры

Контейнер: max-width 1200px, боковые отступы 24px.

Вертикальный отступ между секциями: 96px на десктопе, 56px на мобильном.

Радиус карточек: 24px. Радиус кнопок: 999px (пилюля).

Кнопки: высота 52px, горизонтальный padding 28px.

Внутренний отступ карточек: 24px.

6. Блоки страницы — ровно в этом порядке

Блок 1. Хедер

Липкий, прижат к верху, фон белый с лёгкой тенью при скролле.

Слева: лого — квадрат 36×36 с радиусом 10, заливка orange-500, внутри белая буква «З» жирным. Справа от квадрата — название из BRAND.name.

По центру: 3 ссылки — «Примеры» (#examples), «Как работает» (#how), «Тарифы» (#pricing).

Справа: кнопка-пилюля, заливка navy-900, белый текст, «Начать бесплатно».

Якорь #pricing пока никуда не ведёт — блок тарифов появится в следующем промпте. Оставь ссылку как есть.

Блок 2. Hero

Тёмный блок: фон — градиент из п.2, скруглён 32px, внутренние отступы 64px, текст белый.

H1: «Учёба без ночных дедлайнов»

Подзаголовок, 18px, цвет teal-200: «Пиши работы, решай задачи, собирай презентации и разбирайся в сложных темах — по шагам и с объяснениями»

Кнопка: заливка orange-500, белый текст, «Начать бесплатно»

Ниже — ряд из 4 карточек по данным scenarios. На десктопе 4 в ряд, на планшете 2×2, на мобильном 1 в столбец. Карточка: белая, радиус 24, сверху квадрат-заглушка под иллюстрацию 48×48 с заливкой orange-100, под ним заголовок 16px navy-900 и подпись 14px muted.

Блок 3. Примеры работ

id="examples", светлый фон.

H2 по центру: «Что уже собрали в Зачёте»

Над лентой СЛЕВА — две круглые кнопки-стрелки влево/вправо, диаметр 40. Не по бокам ленты и не под ней.

Горизонтальная карусель по данным examples, карточки одинаковой ширины 300px, промежуток 16px, прокрутка мышью и свайпом.

Карточка: белая, радиус 24. Сверху квадратная иконка 32×32 с заливкой teal-200. Ниже название работы, обрезка ровно в 2 строки многоточием. Внизу мета-строка 13px muted: тип · размер · предмет. Если размер пустая строка — не показывай разделитель.

Блок 4. Показатели

Ряд из 4 плашек по данным stats. Плашки РАЗНОЙ ширины, не равные колонки: пропорции ширины 1.4 / 1 / 1 / 1.3, высота одинаковая 120px, радиус 20. Заливка по полю tone: accent → orange-500 с белым текстом; light → orange-100 с текстом navy-900; white → белый с текстом navy-900; dark → navy-900 с белым текстом. Внутри: крупное значение 36px жирным, под ним подпись 14px. На мобильном — сетка 2×2, ширины равные.

Блок 5. Персонализация

Белая карточка во всю ширину контейнера, радиус 32, отступы 48.

По центру — вертикальный прямоугольник-заглушка под видео: ширина 280, высота 400, радиус 24, заливка teal-200, внутри по центру круглая кнопка play 56×56 с заливкой white.

Под ним H2 по центру: «Подстроится под то, как учишься ты»

Абзац по центру, максимальная ширина 640px, цвет muted: «Кому-то надо закрыть дедлайн сегодня, кому-то — разобраться в теме до конца. Зачёт умеет и так, и так, и не будет решать за тебя, если ты хочешь понять сам.»

Кнопка во всю ширину карточки: обводка navy-900 1px, прозрачный фон, текст «Попробовать» и стрелка вправо.

Блок 6. Как это работает

id="how", светлый фон.

H2 по центру: «Ты ведёшь процесс»

Ряд из 4 карточек по данным steps, равной ширины, радиус 24.

В каждой карточке сверху номер шага в квадрате 32×32 с радиусом 8, ниже заголовок 18px, ниже текст 14px.

Блок 7. Демо результата

Тёмный блок: градиент из п.2, радиус 32, отступы 64.

H2 по центру, белый: «Как выглядит результат»

Подзаголовок по центру, teal-200: «Не стена текста, а документ со структурой, источниками и оформлением»

Ниже — прямоугольник-заглушка под скриншот редактора: ширина 100%, соотношение 16:10, радиус 16, заливка navy-700.

Поверх нижнего края заглушки, со смещением вниз на 40px и по центру — белая карточка шириной 420px, радиус 24, отступы 24. Внутри: строка с круглой аватаркой-заглушкой 40×40 и подписью «Катерина, СПбГУ» 14px; ниже заголовок работы 16px жирным «Влияние крещения Руси на становление государственности»; ниже 3 строки текста 13px muted с обрезкой многоточием; внизу ряд из 3 мета-меток 12px в плашках bg: «Реферат», «156 460 симв.», «48 страниц».

Ровно 3 метки, процент уникальности НЕ добавляй.

7. Границы этого промпта

Сделай только перечисленные 7 блоков и только страницу /.

НЕ добавляй: блок с экспертами и рекомендациями, сравнение с другими нейросетями, отзывы, тарифы, блок Telegram, FAQ, SEO-текст, футер, другие страницы, авторизацию, роутинг помимо главной.

Не придумывай дополнительных секций и не добавляй текстов сверх тех, что заданы выше. Если чего-то не хватает — оставь заглушку, а не додумывай содержание.
